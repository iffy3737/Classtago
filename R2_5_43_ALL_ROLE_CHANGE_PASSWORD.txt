Classtago R2.5.43 — All-Role Self-Service Change Password
=========================================================

Scope
-----
Adds a secure self-service Change Password action for every authenticated Classtago role through the shared application shell.

Behavior
--------
- Available from the authenticated Top Bar on desktop and mobile.
- School ERP command banner also exposes a visible Change Password action.
- Current password is required and re-verified with Supabase Auth before any credential update.
- New password must be 6–72 characters, must match confirmation, and must differ from the current password.
- Only the signed-in user's own Supabase Auth password is changed.
- User ID/login identity is not changed.
- Successful self-service changes write a compatibility audit event when the local audit surface is available.
- No admin/service-role secret is exposed to the browser.

Preservation / safety
---------------------
- Existing first-login mandatory password-change flow remains unchanged.
- Existing Headmaster password-support/reset workflow remains unchanged.
- No role, membership, school, assignment, Student, Result, Admission or Timetable record is modified.
- No SQL migration is required.
- No Supabase service-role/admin key is added to the client.

Files changed from R2.5.42
--------------------------
- package.json
- src/App.tsx
- src/components/TopBar.tsx
- src/components/ChangePasswordModal.tsx (new)

Preview gate
------------
Before publishing, test one Headmaster, Clerk, Teacher, Student/Parent account where available:
1. Open Change Password.
2. Enter an intentionally wrong current password -> update must be rejected.
3. Enter correct current password + new password + matching confirmation -> success.
4. Logout and verify old password fails and new password succeeds.
5. Confirm User ID and role are unchanged.
