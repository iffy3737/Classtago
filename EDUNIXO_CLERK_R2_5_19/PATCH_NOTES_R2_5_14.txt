WHAT THIS PATCH DOES
1. One responsive EDUNIXO ERP frontend for PC browser, mobile browser and packaged/native app.
2. app.* / erp.* hosts (or explicit app mode) enter the ERP app launcher; the public website remains a separate surface.
3. Packaged native builds keep their special /api routing behavior; browser app uses same-origin /api.
4. Multi-school selection and selected-school context remain validated against authenticated school membership.
5. Premium light app presentation is shared across desktop and mobile, with desktop-width composition at larger viewports.
6. Smart multilingual documents are merged for Question Paper, Certificate Document System and Master Progress Card Template:
   - feature/document profile
   - per-section language
   - per-field language overrides
   - mixed LTR/RTL support
   - script-aware font/direction helpers
7. No generic One Cloud State/workspace-drafts frontend service is included.
8. No Supabase migration, production-record update, destructive SQL or dummy data is included in this ZIP.
