# Classtago R2.5.97 — Combined Subject Same-Teacher Visibility Fix

The Combined Question Paper builder is a Class/Division-level feature. The Question Paper page now queries the dedicated CQP groups across all Subject assignments in the current Teacher Class/Division scope, rather than only the currently selected single-subject assignment.

This specifically supports a single Teacher assigned to both components, e.g. EVS-I + EVS-II. The existing single-subject builder, subject-wise chapters/materials, marks ownership, and collaborative different-teacher workflow remain unchanged.
